# הוראות פיתוח והמשך עבודה
- ערוך רק קבצים תחת `src/`, ואז `node build.js` ו-`node tests/run-tests.js dist/index.html`. אל תערוך `dist/` ישירות.
- סדר המודולים נקבע לפי שם הקובץ (00..99). משתנים גלובליים משותפים (`S`, `R`, `CDB`...). פונקציות הן הצהרות מורמות, ולכן הסדר חשוב רק לביטויים שרצים בעת הטעינה.
- כל שינוי נתונים חייב לעבור `save()` (גוזר יתרות, מסמן גרסאות, שומר ומתזמן סנכרון). אל תכתוב ל-`localStorage` ישירות.
- שדות נגזרים (`pa`,`bl`,`paid`) אינם נשמרים; אל תכתוב אליהם.
- הוספת שדה לרשומה: הוסף ל-`docs/DATA_SCHEMA.md`, בדוק מיגרציה ובדיקת תקינות, והוסף בדיקה.
- שלבים הבאים (לפי הוראת v4): 3ב (חשבונות + Supabase + קבצים), 4 (שעון נוכחות, תעריפים, מיקומים, פרויקטים), 5 (הוצאות, בעלי מקצוע, דוחות מורחבים), 6 (מסמכים/אינטגרציות), 7 (i18n, libphonenumber, מטבעות, אזורי זמן), 8 (אבטחה, PWA, ליטוש).
- Git: `git init && git add . && git commit -m "Easy Record v4 alpha 1"`.
- כל שחרור: עדכן `VERSION`, `CHANGELOG.md`, `APP_VER`, והרץ את הבדיקות.
