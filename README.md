# Easy Record (גרסת אלפא 5.0.0-alpha.1)

אפליקציית ווב בעברית (RTL) לניהול ימי עבודה, לקוחות, תשלומים, חובות, קבלות ודוחות.
זהו **שדרוג** של Easy Record הקיימת, לא אפליקציה חדשה. הגרסאות הקודמות נשמרו בתיקיית `versions/` ולא שונו.

> **סטטוס מול הוראת v5.0: `docs/V5_STATUS.md`.**
>
> **סטטוס חשוב:** זו מסירה של שלבים 1–3 (הגנה על הנתונים, אמינות, סנכרון בתשתית הקיימת) ושל שעון העבודה משלב 4.
> שאר הדרישות (חשבונות משתמשים עצמאיים, מסד Supabase/Firebase, מיקומים, פרויקטים, הוצאות, שפות ועוד) **טרם נבנו**.
> הרשימה המלאה: `docs/FEATURES.md`.

## מה חדש ב-v4
- **הפרדה בין יום עבודה לתשלום:** יום עבודה נשאר רשומה אחת (למשל 600 ₪). תשלומים הם ישות נפרדת (תאריך, סכום, אמצעי תשלום, אסמכתה/הערה) ויכולים לכסות כמה תשלומים ליום אחד, או תשלום אחד לכמה ימים. יתרות מחושבות אוטומטית.
- **מיגרציה בטוחה** מהמבנה הישן, עם גיבוי גולמי לפני השינוי, בדיקת סכומים לפני/אחרי, וחזרה לנתונים הישנים.
- **שמירה אוטומטית** ב-IndexedDB וגם ב-localStorage, עם סטטוס שמירה אמיתי. האחסון של v4 נפרד מזה של הגרסה הישנה, והנתונים הישנים לא נכתבים ולא נמחקים.
- **גיבוי ZIP מלא** (כולל קבלות ותמונות), ייבוא ZIP/JSON (גם ישן), תצוגה מקדימה, מיזוג או החלפה, שחזור אטומי, וגיבוי מוצפן בסיסמה.
- **שעון עבודה** עם הפסקות, נטו/ברוטו, שכר יומי/שעתי, תיקון עם היסטוריה, תקין בחצות ובשעון קיץ.
- **סנכרון ברמת רשומה**: מזהה, יצירה, עדכון, גרסה, מחיקות מתועדות, זיהוי התנגשויות ובחירה ידנית, עבודה ללא אינטרנט ותור שינויים, "סנכרן עכשיו".

```
src/js/40-backup.js       ייצוא/ייבוא JSON ו-ZIP, הצפנה, שחזור

```

## בנייה והרצה
```
node build.js                 # יוצר dist/index.html
npm install                   # puppeteer + jszip לבדיקות בלבד
node tests/run-tests.js dist/index.html [נתיב-ל-chromium] [נתיב-ל-jszip.min.js]
```
משתני סביבה: `PUPPETEER`, `CHROME`, `JSZIP`. את `dist/index.html` אפשר לארח כקובץ סטטי (HTTPS), או לפרסם כ-Artifact ב-Claude.
JSZip מוטמע בקובץ. ייצוא Excel (SheetJS 0.18.5) וגופנים (Google Fonts) נטענים מהרשת; בלעדיהם Excel לא יעבוד והגופן יהיה גופן מערכת. ראה `docs/THIRD_PARTY.md`.

## מעבר בטוח מהגרסה הפעילה (חובה לקרוא)
1. **גבה את הנתונים מהאפליקציה הפעילה** לפני כל מעבר: הגדרות > גיבוי > "העתקת גיבוי" (או ייצוא JSON) ושמור את הקובץ במקום בטוח.
2. v4 לא מחליפה את האפליקציה הפעילה. כל פרסום נפרד הוא קישור חדש עם אחסון נפרד (לא נוגע בנתונים הקיימים).
3. כדי לבדוק v4 עם הנתונים שלך: פתח את v4 בקישור נפרד וייבא את קובץ הגיבוי (הגדרות > גיבוי > ייבוא). אחרי הייבוא השווה לקוחות, ימי עבודה, סכומים, תשלומים ויתרות מול האפליקציה הישנה.
4. רק אחרי ההשוואה החלט אם לעבור. אל תמחק את הגרסה הישנה.
פירוט: `docs/MIGRATION_AND_ROLLBACK.md`.

## שימוש באייפון
פתח את הקישור ב-Safari, כפתור שיתוף > "הוסף למסך הבית". הנתונים נשמרים בדפדפן שממנו הוספת. אין עדיין PWA מלא עם עבודה אופליין של האפליקציה עצמה (ראה מגבלות).

## גיבוי ושחזור
`docs/BACKUP_AND_RESTORE.md`. בקצרה: הגדרות > גיבוי ושחזור > ZIP מלא / ZIP מוצפן / JSON. בייבוא מוצגת תצוגה מקדימה ואז בוחרים מיזוג (מומלץ) או החלפה מלאה (עם אזהרה). לפני כל ייבוא נוצר גיבוי אוטומטי.

## סנכרון
`docs/SYNC.md`. הסנכרון משתמש כרגע בשירות הענן של סביבת Claude (חשבון Claude), ולא בחשבון משתמש עצמאי של האפליקציה. קבלות ותמונות **לא** מסונכרנות בין מכשירים.
